# vim-key

| Key              | สิ่งที่ทำ                                           |
| ---------------- | --------------------------------------------------- |
| `0`              | ไปต้นบรรทัด                                         |
| `$`              | ไปท้ายบรรทัด                                        |
| `.`              | ทำสิ่งที่ทำก่อนหน้า                              |
| `/`              | ค้นหา                                     |
| `:%s`            | ค้นหาด้วย command ทำอย่างอื่นได้ด้วย                           |
| `a`              | Insert หลัง cursor                                  |
| `A`              | Insert ท้ายบรรทัด                                   |
| `Alt+j`          | ย้ายบรรทัดขึ้น                    |
| `Alt+k`          | ย้ายบรรทัดลง                   |
| `b`              | ไปต้นคำก่อนหน้า                                     |
| `C`              | ลบจาก cursor ไปขวา แล้วเข้า Insert      |
| `cc`             | ลบทั้งบรรทัดแล้วเข้า Insert                   |
| `ci{object}`     | เข้า Insert ด้านใน |
| `ciw`            | ลบคำปัจจุบันแล้วเข้า Insert                    |
| `Ctrl+d`         | เลื่อนลงครึ่งหน้าจอ                                 |
| `Ctrl+j`         | ลง 5 บรรทัด                |
| `Ctrl+k`         | ขึ้น 5 บรรทัด              |
| `Ctrl+r`         | Redo                                                |
| `Ctrl+u`         | เลื่อนขึ้นครึ่งหน้าจอ                               |
| `D`              | ลบจาก cursor ถึงท้ายบรรทัด                          |
| `dd`             | ลบทั้งบรรทัด                                        |
| `dw`             | ลบจาก cursor ไปถึงคำถัดไป                           |
| `e`              | ไปท้ายคำ                                            |
| `Esc`            | กลับ Normal                                |
| `G`              | ไปบรรทัดสุดท้าย                                     |
| `gg`             | ไปบรรทัดแรก                                         |
| `h`              | เลื่อน cursor ซ้าย                                  |
| `i`              | Insert ก่อน cursor                                  |
| `j`              | เลื่อน cursor ลง                                    |
| `J`              | รวมบรรทัดถัดไปเข้ากับบรรทัดปัจจุบัน                 |
| `k`              | เลื่อน cursor ขึ้น                                  |
| `kj`             | กลับ Normal      |
| `l`              | เลื่อน cursor ขวา                                   |
| `n`              | ไปผลค้นหาถัดไป                                      |
| `N`              | ไปผลค้นหาก่อนหน้า                                   |
| `{number}j`      | ลงตามจำนวนบรรทัด                                    |
| `{number}k`      | ขึ้นตามจำนวนบรรทัด                                  |
| `o`              | แทรก Insert บรรทัดบน                              |
| `O`              | แทรก Insert บรรทัดล่าง                               |
| `p`              | วางหลัง                        |
| `P`              | วางหน้า                     |
| `r`              | เปลี่ยนหนึ่งตัวใต้ cursor                              |
| `u`              | Undo                                                |
| `v`              | เลือกรายตัว                           |
| `V`              | เลือกทั้งบรรทัด                                    |
| `w`              | ไปต้นคำถัดไป                                        |
| `x`              | เหมือนปุ่ม delete                             |
| `yiw`            | copy ตัวที่คลุม                                     |
| `yy`             | copy ทั้งบรรทัด                                    |
| `zt`             | จัดบรรทัดขึ้นบน                 |
| `zz`             | จัดบรรทัดกลางจอ                      |
| `{`              | ไป ช่องว่าง ก่อนหน้า                               |
| `}`              | ไป ช่องว่าง ถัดไป                                  |
| `<<`             | ดัน tab ซ้าย                                 |
| `>>`             | ดัน tab ขวา                                     |
| `gd`               | ไป definition                                  |
| `gr`               | ดู references                                  |
