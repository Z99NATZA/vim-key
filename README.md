# vim-key

| Key              | สิ่งที่ทำ                                           |
| ---------------- | --------------------------------------------------- |
| `0`              | ไปต้นบรรทัด                                         |
| `$`              | ไปท้ายบรรทัด                                        |
| `.`              | ทำคำสั่งแก้ไขล่าสุดซ้ำ                              |
| `/`              | ค้นหาไปข้างหน้า                                     |
| `:%s`            | Search & Replace ทั้งไฟล์                           |
| `a`              | Insert หลัง cursor                                  |
| `A`              | Insert ท้ายบรรทัด                                   |
| `Alt+j`          | ย้ายบรรทัดลง *(custom mapping)*                     |
| `Alt+k`          | ย้ายบรรทัดขึ้น *(custom mapping)*                   |
| `b`              | ไปต้นคำก่อนหน้า                                     |
| `C`              | ลบจาก cursor ถึงท้ายบรรทัดแล้วเข้า Insert mode      |
| `cc`             | ลบทั้งบรรทัดแล้วเข้า Insert mode                    |
| `ci`             | เริ่มคำสั่ง `change inside` ต้องตามด้วย text object |
| `ciw`            | ลบคำปัจจุบันแล้วเข้า Insert mode                    |
| `Ctrl+Backspace` | ลบคำก่อนหน้าใน Insert mode                          |
| `Ctrl+d`         | เลื่อนลงครึ่งหน้าจอ                                 |
| `Ctrl+j`         | ลง 5 บรรทัด *(custom mapping: `5j`)*                |
| `Ctrl+k`         | ขึ้น 5 บรรทัด *(custom mapping: `5k`)*              |
| `Ctrl+r`         | Redo                                                |
| `Ctrl+u`         | เลื่อนขึ้นครึ่งหน้าจอ                               |
| `D`              | ลบจาก cursor ถึงท้ายบรรทัด                          |
| `dd`             | ลบทั้งบรรทัด                                        |
| `dw`             | ลบจาก cursor ไปถึงคำถัดไป                           |
| `e`              | ไปท้ายคำ                                            |
| `Esc`            | กลับสู่ Normal mode                                 |
| `G`              | ไปบรรทัดสุดท้าย                                     |
| `gg`             | ไปบรรทัดแรก                                         |
| `h`              | เลื่อน cursor ซ้าย                                  |
| `i`              | Insert ก่อน cursor                                  |
| `j`              | เลื่อน cursor ลง                                    |
| `J`              | รวมบรรทัดถัดไปเข้ากับบรรทัดปัจจุบัน                 |
| `k`              | เลื่อน cursor ขึ้น                                  |
| `kj`             | กลับสู่ Normal mode *(custom mapping: `Esc`)*       |
| `l`              | เลื่อน cursor ขวา                                   |
| `n`              | ไปผลค้นหาถัดไป                                      |
| `N`              | ไปผลค้นหาก่อนหน้า                                   |
| `{number}j`      | ลงตามจำนวนบรรทัด                                    |
| `{number}k`      | ขึ้นตามจำนวนบรรทัด                                  |
| `o`              | เปิดบรรทัดใหม่ด้านล่าง                              |
| `O`              | เปิดบรรทัดใหม่ด้านบน                                |
| `p`              | วางหลัง cursor / บรรทัดถัดไป                        |
| `P`              | วางก่อน cursor / บรรทัดก่อนหน้า                     |
| `r`              | แทนที่ character 1 ตัว                              |
| `u`              | Undo                                                |
| `v`              | Visual mode แบบ character                           |
| `V`              | Visual Line mode                                    |
| `w`              | ไปต้นคำถัดไป                                        |
| `x`              | ลบ character ที่ cursor                             |
| `y`              | เริ่มคำสั่ง Yank                                    |
| `yiw`            | Yank คำปัจจุบัน                                     |
| `yy`             | Yank ทั้งบรรทัด                                     |
| `zt`             | จัดบรรทัดปัจจุบันไว้ด้านบนของหน้าจอ                 |
| `zz`             | จัดบรรทัดปัจจุบันไว้กลางหน้าจอ                      |
| `{`              | ไป paragraph ก่อนหน้า                               |
| `}`              | ไป paragraph ถัดไป                                  |
| `<<`             | Indent ไปทางซ้าย                                    |
| `>>`             | Indent ไปทางขวา                                     |
